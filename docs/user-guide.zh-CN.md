## 一条记录是什么

MateriaViva 里的每一行是**一个唯一的周期性晶体结构**，不是一条数据库条目。十一个数据库各自描述的同一个
结构，在这里是**一条**记录，并且带着全部十一份描述。这是这个项目的核心，也是第一次用最容易被吓到的
地方——见[为什么一个性质有很多个值](#为什么一个性质有很多个值)。

记录标为**实验**或**候选**，两者从不被悄悄混在一起：

| 标签 | 含义 |
|---|---|
| 实验结构 | 结构是被测量出来的——它出现在真实样品的晶体学数据库里 |
| 计算候选 | 结构来自计算：被预测或弛豫得到，可能可合成也可能不可 |

## 找一个结构

### 元素周期表

每个元素点击时在三个状态间循环：

1. **中性**——不作约束
2. **包含**（绿）——必须含有
3. **排除**（红）——必须不含

表格下方三个按钮决定"包含"的元素怎么被解读：

| 模式 | 含义 | 例：选了 Li、Fe、O |
|---|---|---|
| **Contains all** | 选中的元素都必须有，可以还有别的 | 命中 `LiFePO4`，也命中 `Li2FeO3S` |
| **Contains any** | 至少含其中一个 | 命中 `Fe2O3`、`Li2O`、`LiFePO4` |
| **Exact system** | 只含这些元素，不含任何其他 | 命中 `LiFeO2`，**不**命中 `LiFePO4`——P 不在集合里 |

默认是 Contains all，通常也是你想要的。研究某个特定化学体系、而它的二元子体系是噪声时，用
**Exact system**。

### 化学式输入框

`化学式、化学体系或材料 ID` 三种都接受：

- 化学式——`LiFePO4`
- 化学体系——`Fe-O`
- MateriaViva 的材料 ID——`exp-train-10343`

它和元素周期表是**并用**关系，不是替代关系。

### 高级筛选

数值筛选都是区间，任一端留空即为开区间。值得解释的几项：

| 筛选项 | 需要知道的 |
|---|---|
| **PBEsol 带隙** | 这是 PBEsol 泛函**算出来的**带隙，单位 eV。DFT 带隙系统性偏低：这里是 0 **不能**证明材料是金属，很小的值在现实中可能宽得多。如果你问的是"是不是金属"，请用**金属性**那一项。 |
| **能量高于凸包** | 0 eV/atom 表示在凸包上——0 K 下对分解热力学稳定。越大越亚稳或不稳。 |
| **形成能 / 原子** | 负值表示由单质生成在能量上有利。**这和"高于凸包"不是同一个问题。** |
| **空间群号** | 逗号分隔，如 `62, 225`。 |
| **性质可用性** | 带隙、密度、空间群、形成能、高于凸包、磁性、弹性七个勾选项。筛的是这个性质**有没有被记录**，不是它的数值——是"给我看有弹性数据的"，不是"给我看硬的"。 |
| **数据来源** | 仅实验 / 仅候选。两个都不勾就是全部。 |

筛选项之间是"与"的关系。搜不到东西时，通常是某个数值区间比你以为的窄，或者包含的元素太多。

## 读一个材料

### 基本性质

顶部那一块是每个性质的**代表值**——选一个数出来让页面有东西可显示。**当各来源不一致时，它是其中一个
答案，不是共识值、也不是平均值。** 完整情况在下面。

### 为什么一个性质有很多个值

**跨库性质**会把每个来源库记录的每一个值都列出来，**并且不做调和**。以碳化硅（`exp-train-10343`）为例，
页面上有 **21 个密度值**：

| 数值 | 来源 |
|---|---|
| 3.17137 g/cm³ | aflow |
| 3.24 g/cm³ | amcsd |
| 3.218 g/cm³ | amcsd |
| … | … |

**这不是 bug，是刻意的设计：一个值保留它到来时携带的单位、方法与出处，不会被悄悄平均成一个数。**
两个值不同，可能是用了不同泛函、在不同温度下测的、或者测的是不同样品；而**同一个来源库给出多个值也是
合理的**——它可能对同一个结构持有多条记录。

每一行都带**方法**和**来源**，你据此判断哪一个回答的是**你的**问题。如果必须取一个数，**按方法选，
不要默认排在最上面的那个最好。**

#### ×N 标记是什么意思

一个来源库还可能对**同一个晶体持有多条记录**——AFLOW 对某些结构保留了十几个计算条目——指纹去重会把
它们全部匹配到同一个 MateriaViva 材料上。当这些记录**完全一致**时，逐条打印出来就是同一行反复出现，
读起来像 bug 而不像数据。

因此，**性质、数值、单位、方法、来源全部相同**的行会合并成一行并标 `×N`；把鼠标停在标记上可以看到它
代表的那些上游 id。**任何有差异的都不会被合并**：硫化镉会把 `band gap 1.1886 eV ×3` 和
`band gap 1.1883 eV ×3` 显示成两行，尽管只差三个千分之一 eV。

### 结构从哪来

**来源数据库**列出贡献的库，以及每一个是**怎么匹配**到这条记录的：

| 标记 | 含义 |
|---|---|
| **指纹匹配** | 按结构指纹匹配上的——这些库描述的是同一个晶体，但彼此没有共用标识符 |
| **ID 匹配** | 通过来源自己引用的标识符匹配，例如 ICSD 号 |
| **贡献结构** | 这个来源就是该结构进入 MateriaViva 的入口 |

碳化硅有 11 个贡献库：24 条按指纹匹配、8 条按 ICSD 号匹配、1 条贡献了结构本身。每条各自带许可，就显示
在旁边。

**下载 CIF** 给出的是统一后的结构记录。

## 两个 3D 视图

查看器有两个标签页，是**两个不同的引擎**，各有所长：

| | OVITO 渲染 | Interactive 3D |
|---|---|---|
| 是什么 | 服务端产出的光线追踪静态图 | 浏览器内的实时 WebGL 场景 |
| 适合 | 出图、发表级静帧 | 查看、旋转、看内部 |
| 需要 | 服务端装有 OVITO | 浏览器支持 WebGL |

如果 **OVITO 渲染**标签是灰的，说明你连的这台服务器没有配置 OVITO 渲染器；这种情况下 Interactive 3D
照常可用，并且会默认打开。

查看器下方的控件：

- **View**——`I` 等轴测、`F` 正视、`T` 俯视。相机预设，**两个引擎都生效**。
- **Model**——球棍模型，或空间填充。
- **Cell**——重复几个晶胞，以及是否画出晶胞边线。
- **Quality**——preview 或 high。这是光线追踪质量，所以**只出现在 OVITO 标签页**；实时视图没有对应的
  设置。

Interactive 3D 里可以拖拽旋转、滚轮缩放、右键拖拽平移。

## 你不会看到的东西

MateriaViva 编目的一部分数据库**不可再分发**。对这些来源，记录里保留名称、链接、许可与标识符，但**不含
它的数据**——授权无法确认的，默认不公开。逐个来源的处置见
[`dataset-acquisition.zh-CN.md`](dataset-acquisition.zh-CN.md)。
